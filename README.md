# Bot Chess

Slick chess PWA — play against a client-side bot. No account.

**Live:** https://eliotmjohnson.github.io/Bot-Chess/

## Stack

- Vite + React + TypeScript
- `chess.js` for rules
- Minimax bot (easy / medium / hard)
- `vite-plugin-pwa` + GitHub Pages

## Dev

```bash
npm install
npm run dev
npm run build
npm run deploy
```
